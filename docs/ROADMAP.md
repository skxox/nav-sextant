# nav-sextant 功能任务清单

> **定位：自动决策、人工执行。** 系统每日无人值守产出可执行的 BUY/SELL/HOLD 决策，人负责最后下单。任何功能取舍以此校验：让决策更准、更稳、更可追溯的做；越过"人执行"边界的砍。
> 维护规则：新想法先入「待办池」；动手时移入「进行中」；完成后勾选并归档到「已完成」。想过但决定不做的，记入「明确不做」，防止反复。

## 📋 待办池（按决策链路分组，沿「数据 → 因子 → 决策 → 执行 → 复盘 → 运行」推导）

> 目标架构：预测与决策解耦——预测层只输出数值，决策层消费契约，LLM 不越过风控。骨架已就位，以下为纵向加深项。

### A. 决策质量与复盘（自动决策成立的前提：知道决策准不准）

- [ ] 辩论层 A/B 验证：开/关 Bull/Bear 辩论对信号质量的影响
- [ ] IC 调权验证报告：跑一段时间后出对比（开 vs 关的信号质量差异），支撑默认开关决策
- [ ] 决策可复现性：同日重跑的决策一致性度量（LLM 采样漂移 → 低温度/多数投票收敛）
- [ ] 完整账户记账（xalpha 对标）：申购/赎回/分红/手续费全流水、持仓成本精确核算、收益率归因——现有 ledger 只有份额/成本对账
- [ ] T-1 估算误差度量：预测净值 vs 官方净值的每日偏差跟踪——它是判断 B 组 ML 模型该不该做的前提
- [ ] 回测与实盘一致性：当前回测是纯阈值策略，证明不了"多因子+Agent+辩论"实盘管道有效——回测加分层模式（关 Agent / 关辩论）做归因，前向复盘是唯一完整验证

### B. 净值预测层升级（单一算法 → 按基金类型多策略）

- [ ] 按基金类型切换估值算法：场内 ETF 用实时价格 / 场外指数基金用持仓加权 / QDII 用混合估值（含汇率）——目前全走同一套前十大重仓近似
- [ ] QDII T-0/T-1 净值预测：海外持仓 + 汇率 + 期货行情（可参考 xalpha QDIIPredict 思路；前提：实际持有 QDII 基金）
- [ ] ML 时序模型（LSTM/Transformer）与透明模型并联对比：仅在复盘证明透明模型误差不可接受时引入，透明可解释优先
- [ ] T-1 估算精度提升：扩样本或引入更好 proxy（README 已知限制）
- [ ] 行业指数自有 PE 历史积累：脱离蛋卷外部分位依赖（需数据积累时间）

### C. 因子与风控扩充

- [ ] 宏观/市场状态因子：VIX、信用利差、市场状态识别（牛市/震荡/熊市，可参考 HMM regime 思路）作为编排层输入
- [ ] 预测概率化输出 + 校准：composite score 显式化为"未来 N 日上涨概率"，用可靠性曲线 / Brier 分数度量校准度（说 60% 时是否真 60%），IC 调权即校准回路的一环——"综合各种信息做预测"的工程化形态
- [ ] 跨资产领先信号：股债性价比（ERP）、信用利差领先股市 3-5 日（llm-quant F1 家族实证思路）作为择时增强输入
- [ ] 行业集中度风控：多只基金重仓同一行业（如均重仓白酒）时组合层面降仓
- [ ] 组合级资金分配：多基金信号冲突时的总仓位预算与分配规则
- [ ] 极端行情模式：急跌/流动性危机阈值触发的保守模式明确规则
- [ ] 深度风控（参考 llm-quant，按需裁剪不凑数）：波动率目标仓位 / ATR 仓位控制、CVaR 尾部风险约束、持仓间动态相关性监控——现有 3 条硬约束之外的第二梯队
- [ ] 智能定投择时：低估多投/高估少投的定投策略模式（与 BUY/SELL 并行的第二种用法）
- [ ] 因子库扩充：动量/估值/风险三类之外，补量价、资金流等因子
- [ ] 因子失效监控：因子 IC 连续为负时告警，提示模型退化

## 💤 明确不做 / 暂缓

- **全自动交易执行（自动下单）**：决策系统只到信号为止，执行由人确认——风控红线原则的延伸
- **全市场选基引擎**：自用固定基金池，选基是低频人工决策，系统只做已选基金的择时
- **ML 模型默认启用**：透明持仓穿透模型可解释、可调试；ML 仅作为并联对比候选
- **MCP 对外暴露**：自用无外部消费者，OpenAI 兼容 API 已够用
- **推翻重写/换基座**：现有骨架（契约化决策 + 确定性风控 + fail-closed）已对齐目标架构，只做纵向加深
